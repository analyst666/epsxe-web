# ePSXe Web — PlayStation 1 no Navegador

Versão Web moderna e completa baseada na engenharia reversa do **ePSXe for Android 2.0.14**.

## Recursos Principais
- 🌙 **Tema Escuro Moderno (Dark Mode)** com visual limpo e responsivo.
- 💿 **Área de Anexar Jogos (Drag & Drop)**: Suporta `.bin`, `.cue`, `.iso`, `.img`, `.chd`, `.pbp`, `.ecm`, `.zip`, `.7z`.
- 🧩 **Agrupador Inteligente**: Detecta `.cue` com múltiplos `.bin` (faixas de áudio CDDA) e empacota automaticamente em memória para tocar as músicas perfeitamente.
- 🎮 **Suporte Completo a Controles**: Conecte controles de PS4, PS5, Xbox ou genéricos via USB/Bluetooth (detecta automaticamente com vibração, analógicos e zonas mortas configuráveis).
- 💾 **Saves & Savestates**: 5 slots de salvamento rápido por jogo e suporte a Memory Cards originais.
- ⚡ **Turbo & Atalhos**: `Select+R1` (salvar), `Select+L1` (carregar), `Select+R2` ou `Espaço` (aceleração turbo), `Esc` ou botão `Home` (menu de pausa).
- 🔍 **Banco de Dados Oficial**: ~11.000 jogos do ePSXe pré-catalogados com identificação automática de capa, região e gênero por serial.

## Como Iniciar
1. Dê dois cliques em `iniciar_epsxe_web.bat` na pasta raiz.
2. Abra seu navegador em `http://127.0.0.1:8765/`.
3. Arraste qualquer jogo baixado para a tela e clique para jogar!
